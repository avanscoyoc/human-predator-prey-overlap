## **File Descriptions**

### *Scripts:*
There is 1 script used to run this analysis.

* **VanScoyoc_et_al_plotting_results.Rmd**  - This file loads dataset, formats data, calculates statistics, and creates Figure 2 from manuscript.

### *Metadata Files:*
There is 1 file that explains how we compiled the dataset, 1 script describing the metadata for this analysis, and

* **VanScoyoc_et_al_table1.xlsx** - This table summarizes site descriptions, human activity level, and method used to calculate predator-prey activity ratio and overlap coefficient of each study in analysis (n = 19).

* **VanScoyoc_et_al_metadata.md** - This file defines the column names in the *VanScoyoc_et_al_fulldata.csv* file and how each data column was calculated. 

### *Data Files:*
There is 1 data file needed to recreate Figure 2 from our manuscript.

* **VanScoyoc_et_al_fulldata.csv** - This files is the full dataset used in our analysis with the predator-prey pairs, activity ratios at high and low human use, normalized activity ratios, relative normalized activity ratios, overlap coefficients, overlap confidence intervals, change in overlap, and functional traits for 19 studies and 184 predator-prey dyads. For information on how this dataset was compiled, see the *VanScoyoc_et_al_table1.xlsx* file, for explanation of the columns in this dataset see the *VanScoyoc_et_al_metadata.md* file.
