## **File Descriptions**

### *Scripts:*
There are 2 scripts that created the case study Figures in this paper.

* **VanScoyoc_et_al_Figure2.Rmd**  - This file loads dataset, formats data, calculates statistics, and creates Figure 2 from manuscript.

* **VanScoyoc_et_al_Figure3.Rmd**  - This file loads dataset, formats data, and creates Figure 3 from manuscript.

### *Data Files:*
There is 1 data file needed to recreate Figure 2 and Figure 3 from our manuscript.

* **VanScoyoc_et_al_fulldata.csv** - This files is the full dataset used in our analysis. It includes the predator-prey pairs, activity ratios at high and low human use, normalized activity ratios, relative normalized activity ratios, overlap coefficients, overlap confidence intervals, change in overlap, and functional traits for 19 studies and 178 predator-prey dyads. For information on how this dataset was compiled, see the *VanScoyoc_et_al_table1.xlsx* file, for explanation of the columns in this dataset see the *VanScoyoc_et_al_metadata.md* file. 

### *Metadata Files:*
There is 1 file that explains how we compiled the dataset, 1 file describing the metadata for this analysis.

* **VanScoyoc_et_al_table1.xlsx** - This table summarizes site descriptions, human activity level, and method used to calculate predator-prey activity ratio and overlap coefficient of each study in analysis (n = 19).

* **VanScoyoc_et_al_metadata.md** - This file defines the column names in the *VanScoyoc_et_al_fulldata.csv* file and how each data column was calculated.
