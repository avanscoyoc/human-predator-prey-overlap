
# Van Scoyoc, A., Smith, J.A., Gaynor, K.M, Barker, K., Brashares, J.S. The influence of human activity on predator-prey spatiotemporal overlap. Journal of Animal Ecology. 
---

Temporal activity and functional trait data for 178 predator-prey dyads from 19 published camera trap studies of terrestrial mammals in paired settings of high and low human use. Includes R scripts and dataset used to create figures that assess how human activity influences predator-prey activity and overlap.

### File descriptions

* **human-predator-prey-overlap.Rproj** - This file loads all project files and folders into an R project working directory. 

* **VanScoyoc_et_al_Figure2.Rmd**  - This file loads dataset, formats data, calculates statistics, and creates Figure 2 from manuscript.

* **VanScoyoc_et_al_Figure3.Rmd**  - This file loads dataset, formats data, and creates Figure 3 from manuscript.

* **VanScoyoc_et_al_data.csv** - This files is the full dataset used in our analysis. It includes the predator-prey pairs, activity ratios at high and low human use, normalized activity ratios, relative normalized activity ratios, overlap coefficients, overlap confidence intervals, change in overlap, and functional traits for 19 studies and 178 predator-prey dyads. For information on how this dataset was compiled, see the *VanScoyoc_et_al_table1.xlsx* file, for explanation of the columns in this dataset see the *VanScoyoc_et_al_metadata.md* file. 

* **VanScoyoc_et_al_table1.xlsx** - This table summarizes site descriptions, human activity level, and method used to calculate predator-prey activity ratio and overlap coefficient of each study in analysis (n = 19).

* **VanScoyoc_et_al_metadata.md** - This file defines the column names in the *VanScoyoc_et_al_fulldata.csv* file and how each data column was calculated.
